# Sales and Construction Analytics Dashboard (Excel)

This Excel dashboard provides insights into sales performance, construction cost trends, contract value distribution, labor cost analysis, and regional KPIs.

## 📊 Tools Used
- Microsoft Excel
- Pivot Tables
- Slicers & Timelines
- Conditional Formatting
- Charts & KPI Cards

## 🧠 Key Insights
- Total contract value by client and region  
- Monthly actual spend trends  
- Labor cost comparison across regions  
- Equipment cost and overhead cost analysis  
- Department-wise salary and performance insights  

## 📁 Files Included
- `Sales_Construction_Analytics_Dashboard.xlsx`
- Supporting data files (if any)

## 🧰 Dashboard Features
- Interactive slicers for Region, Client, Contract Type, Department  
- Dynamic charts for monthly spend and cost trends  
- KPI cards for contract value, labor cost, equipment cost  
- Clean layout for management reporting
